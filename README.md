# Zed Config

My personal configuration files for the Zed editor (version 0.225.10).

## 🚀 Quick Start

1. Clone this repo to your Zed config directory:
    ```bash
    git clone https://github.com/juanlopez4691/zed-config ~/.config/zed
    Restart Zed or reload config (cmd-shift-p → "zed: reload config").
    ```

## 📁 What's Included

- settings.json:
  Editor settings, themes, UI tweaks
- keymap.json:
  Custom keybindings (Vim-inspired + custom)
- tasks.json:
  Tasks including external lazygit via Ghostty terminal
- .gitignore:
  Excludes Zed state files (.mdb prompts, cache, etc.)
